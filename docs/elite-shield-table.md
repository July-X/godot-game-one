# 精英怪护盾吸收表

## 护盾属性

| 属性 | 值 |
|------|-----|
| 基础护盾量 | 80 |
| 难度加成 | × (1 + encounter_count × 0.1) |
| 是否恢复 | 否（吸收完即永久消失） |
| 恢复触发 | 被击破后永不恢复 |
