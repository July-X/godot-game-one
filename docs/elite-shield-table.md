# 精英怪护盾/血量吸收表

## 成长公式

```
护盾 = int((80 + 玩家等级 × 10) × 难度系数)
血量 = int((50 + 玩家等级 × 15) × 难度系数)
难度系数 = 1.0 + (遭遇次数 - 1) × 0.1
```
