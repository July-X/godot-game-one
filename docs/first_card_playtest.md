# 首张卡试玩单

约 5 分钟。一名新人操作，观察者记下动作和原话。手机横屏启动后，从标题页点「试飞任务 → 首卡试飞」。

## 分配第一轮

按到场顺序交替分配 A、B、A、B。观察者点好「试飞 A」或「试飞 B」，到选卡画面再把手机交给玩家，统一使用下面的问法。第一轮由玩家自己选卡和走位。片段结束后可点「再选一张」重试同版，点「返回标题」可重新选版。

## 读给玩家

1. 「看一下这组卡。你打算选哪张？你预期选完会发生什么？」
2. 「按你平时的方式玩完接下来的一波。怎么飞由你决定。」如果选择已经超时，就继续正常玩。
3. 「哪一刻让你觉得卡生效了？你是怎么认出来的？有没有你以为会发生、最后没看出来的事？」

## 按卡记第一轮

记下版本、卡名、按键／点按／超时、第一次转向和攻击、首次实际结果与累计失血，以及玩家自己的解释。安卓可从本机系统日志核对 `[TRIAL_EVENT]`。强退导致日志缺项时，按现场观察记录中途退出。表中无需填写姓名。

| 首选卡与可观察的结果 | A 首轮 | B 首轮 |
| --- | --- | --- |
| 贯穿弹芯 · 同一实弹打到两架 |  |  |
| 溅射弹头 · 非直接目标被扣血 |  |  |
| 擦弹专注 · 实际新增一层 |  |  |
| 威力 +3 · 数值对照 |  |  |

对前三张卡，分别记录「做到且认出」「做到但没认出」「未做出」「中途退出」。威力卡记玩家观察到的变化和是否完成。原话与观察者的推测分开。

## 第二轮只作追问

记完第一轮再决定是否重试或换版。可以问「如果再飞一次，你想试什么？」，然后观察他如何验证自己的猜想。另记第二轮的版本、卡片和动作，不计入首轮统计。

## 贯穿的两分钟手机盲试玩

1. **前 30 秒**。观察者从标题进「试飞任务 → 首卡试飞」，选「试飞 A」，把手机交给第一次接触这波的玩家。只说「看卡，选你想试的，按平时的方式飞完这一波」。让玩家自己选卡和飞，照实记下其他卡或十秒超时。
2. **接下来 45 秒**。问「你觉得卡在什么时候生效了？你当时在做什么？」记下原话、第一次改变航线的时刻和是否失血。如果玩家选了贯穿，观察者可以在事后用录屏确认是否有同一发实弹打中两架左队敌机。只看得出先后击毁或日志里只写了「首次贯穿」时，首队双中记为「未确认」。
3. **最后 45 秒**。有时间可请玩家再试一轮，先问他想尝试什么。第一轮记录单独保留，按「做到且认出」「做到但没认出」「未做出」「中途退出」填写，观察到的动作和对意图的推测分开写。
