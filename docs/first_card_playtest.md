# 首张卡试玩单

约 5 分钟。一名玩家操作，一名观察者记下原话。把下面三段读给玩家即可。

1. 「请从标题页选『首卡试飞』。按你习惯的方式玩，看到第一组卡时把你正在考虑的那张读一下。你觉得选了它会发生什么？」
2. 「选你想用的卡，继续玩完接下来的一波。怎么飞由你决定。」如果选择已超时，照常玩，让观察者记下系统选了哪张。
3. 「刚才哪一刻让你觉得这张卡生效了？有没有哪一刻你以为会生效，却没看出来？如果再来一次，你想怎么试？」

观察者在第一轮结束前只记录，不提示路线或解释卡面。记下原话、卡名、选择方式，以及选完后十秒内的第一次转向与攻击。需要再玩时点「再选一张」，同一名玩家的第二轮单独记录。

在项目根目录运行 `godot --path .` 即可从标题页开始。
