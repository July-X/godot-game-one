# 首张卡试玩单

约 5 分钟。一名玩家操作，一名观察者记下原话。两轮都从首张卡开始。

## 读给玩家

1. 「看一下这组卡。你打算选哪张？你预期选完会发生什么？」
2. 「按你平时的方式玩完接下来的一波。怎么飞由你决定。」如果选择已经超时，就继续正常玩。
3. 「刚才哪一刻让你觉得这张卡生效了？有没有哪一刻你以为会生效，却没看出来？如果再来一次，你想怎么试？」

## 观察者用

先开 A，玩家回答后再开 B，两轮都读同样的话。让玩家自己选卡和走位。选了同一张卡时，注明这对可以直接对照。两轮之间记下卡是否换了、上一轮留下的印象。第二轮的熟悉度也可能改变动作。

```sh
godot --path . res://scenes/first_card_trial.tscn -- --from-draft --trial-log
godot --path . res://scenes/first_card_trial.tscn -- --from-draft --trial-log --trial-hint
```

| 记录 | A | B |
| --- | --- | --- |
| 观察到的动作 | 卡名，按键／点按／超时，首次转向、停留位置和攻击 | 同左，另记玩家何时看见提示 |
| 玩家原话 | 选卡前预期，何时看到效果，自己如何解释原因 | 同左，另记提示是否读懂 |
| 游戏事件 | 首次结果时间，累计失血 | 同左 |
| 失败或中断 | 从未打出效果、打出了却没认出、选卡超时或提前结束 | 同左，另记提示出现太晚或挡住操作 |
| 观察者推测 | 写在此栏，和原话分开 | 写在此栏，注明可能受上一轮影响 |

每轮单独记录，无需填写玩家姓名。脚本日志能核对命中与计层，玩家有没有看懂以原话和动作判断。
