# 联机 Bug 单（2026-05-11）

## 背景
- 当前版本联机主链路已可用（可建房/发现/加入/基础战斗）。
- 以下问题为下一轮联机体验优化的重点缺陷，按优先级排序。

## P0

### 1) 护盾同步错误（A/B 屏状态不一致）
- 现象：联机时玩家 A/B 护盾层数出现“同时获得、同时消失”，且两端显示不一致。
- 期望：护盾应按玩家独立维护（A 触发只影响 A，B 触发只影响 B），并在双端一致显示。
- 验收：
  - A 拾取护盾后仅 A 护盾增加，B 不变。
  - A 受击消耗护盾时仅 A 变化，B 不变。
  - 两端 HUD 护盾层数与实际受击结果一致。

### 2) 排行榜/得分未同步显示双人数据
- 现象：排行榜（或结算得分显示）没有正确展示 A/B 两个玩家得分。
- 期望：联机场景下应同时展示 A/B 分数与排名信息。
- 验收：
  - 双端都能看到 A/B 两个玩家的实时或结算得分。
  - 同一事件（击杀/奖励）后，A/B 双端得分变化一致。

## P1

### 3) 双屏同步帧率偏低，体感卡顿
- 现象：联机中存在明显卡顿，双屏运动/战斗不同步体感较差。
- 期望：提升同步流畅度，降低位置与状态抖动。
- 验收：
  - 双端玩家/怪物移动更连续，减少瞬移和抖动。
  - 战斗高峰期（子弹较多）仍可保持可玩流畅度。

### 4) 精英怪掉落加倍，并让联机双方均分掉落收益
- 现象：当前精英怪掉落对联机协作激励不足，掉落分配策略不明确。
- 期望：精英怪掉落数量加倍，并按双人均分策略分配收益。
- 验收：
  - 精英怪死亡后掉落总量相较当前版本翻倍。
  - A/B 两个玩家都能稳定获得均分收益（不偏向单端）。
  - 双端属性增益显示一致。
