# 联机掉落结算与拾取反馈

同局的物品由房主从实体表登记和移除。加入端只能请求房主检查吸附，房主用已同步的飞机位置、现有感应半径和归属校验。房主确认物品到达吸附者后，先移除可拾取实体，再结算一次。固定归属和先吸附者锁定沿用现有规则，过期回收仍按原规则给房主结算。

每件物品用一条可靠结果同步退场，两边在同一个世界落点收拢精灵，约 0.15 秒释放显示节点。加入端收到结果即可开始退场，再等常规 100 毫秒状态同步包含这次结算后显示奖励，播放一次确认音。核心断环和奖励字样只给拾取者。属性达到上限或冷却已就绪时显示拾取确认，文案以实际收益为准。

生成、吸附请求、退场与补发带局号。已退场的物品 ID 拒绝重复结果和过期生成，重试后拒绝旧局数据，即使物品 ID 在新局重用。加入端缺失的在场物品沿既有实体快照补发，既有副本保持原节点。主机和加入端须使用同一版本。连接断开仍沿用单人回退，同一连接内的重试和补快照有回归覆盖。

## 对照结果

基线为 `ec746ea`。同机 Godot 4.6.2、ENet 回环，双方互换房主，各执行四个普通样本。墙钟在逐帧观察点采样，约一帧内可有取样先后差。典型值取中位数。

| 指标 | 基线典型／最大 | 修复后典型／最大 |
|---|---:|---:|
| 出生到拾取者提示 | 90 / 200 毫秒 | 152 / 296 毫秒 |
| 房主数值可见到加入端退场 | 8 / 18 毫秒 | 1 / 15 毫秒 |
| 房主数值可见到加入端数值可见 | 112 / 145 毫秒 | 105 / 138 毫秒 |
| 拾取者数值可见到提示 | −42 / 0 毫秒 | 8 / 42 毫秒 |
| 每件掉落的可靠消息数 | 3–4 条，共 28 条 | 2–3 条，共 20 条 |

消息数是在临时副本记录实际发送，含生成、吸附提示、退场与独立反馈。既有状态快照和实体位置包仍按原频率发送，表内省略测试注入的重发。基线加入端提示有提前 115 毫秒的样本，而且拾取确认声出现在房主端。新版等待已结算数值，延迟夹具中加入端退场后等待 296–298 毫秒，期间无奖励文字及确认声。

20:9 右缘的核心提示框原先与战斗区域交集为 0／120 个画布单位，原图提示框内没有暖白字色像素。修复后交集为 120／120，新提示框内取到 306 个暖白像素。普通提示按拾取落点变换到界面画布，实拍同时检查了 20:9 的横偏和 4:3 的纵偏。右下提示避开技能按钮所在矩形，核心文字继续在敌弹下方绘制。

图形拾取专题两组各 77 项通过。常规联机 40 项、跨画幅左右房主各 57 项、救援 79 项、Boss 124 项、战斗画面 21 项及移动端 13 项通过。Boss 旧夹具在距物品 602 单位的位置发吸附请求，修复后按实际 438 单位感应范围拒绝。夹具现先移动到范围内，继续验证速射归属，以及房主拒绝加入端请求专属核心。
