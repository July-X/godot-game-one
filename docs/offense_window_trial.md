# 45 秒进攻窗口试飞

从标题点「进攻窗口 · 45 秒」，选贯穿弹芯或高爆弹头。选卡后开始 45 秒计时。飞行中可点「重试」，桌面也可按 R。结果画面可重开或返回标题。这个入口只记录本次试飞的击杀和时间，普通进度和排行榜照原流程处理。

五组交战各占 540 个物理帧。每组左侧三机先纵向对齐，前两架在第一轮扇弹过后散开。右侧两机从不同位置入场后聚拢。左右后排用同样的暖色收束弧提示即将开火。每组第 166、244 帧由还在场的后排各发三颗慢弹。射线留出中路。已经打出的弹继续飞行，击毁发射者会取消它随后的一股。下一组左队的轴线会移位。

## 本地复跑

同一画幅内，两张卡复用种子 1121 和相同的鼠标航线或模拟摇杆输入。探针逐组对照实际出生，比较 2,700 帧位置摘要，记录后排死亡和真正加入场景的弹体。它还核对两种画幅从标题进入、第二指点卡时保持移动、飞行中重试以及返回清理。日志和 `windows.json` 写在指定目录。

| 航线 | 首组左后排击毁帧 · 贯穿／威力 | 第 166 帧实际弹数 · 贯穿／威力 |
| --- | --- | --- |
| 鼠标提前抢位 | 158／174 | 3／6 |
| 模拟摇杆提前抢位 | 156／171 | 3／6 |
| 鼠标晚起手 | 237–238／239 | 6／6 |
| 鼠标走中路 | 两边都存活 | 6／6 |

每次都跑到第 2,700 帧。两种画幅左右流量结果一致。两张卡走中路都零失血。模拟摇杆抢位整局贯穿零失血、威力失去 1 点机体生命。初版第 152 帧发射时，模拟摇杆还在交火。把试飞首轮延到第 166 帧后，同航线的提前击毁能取消左路三发，右路三发照常出生。

## 无提示真人盲玩

1. 从标题进试飞，把手机交给第一次体验的人。只说「看一下卡片，选你想试的，按平时的方式飞完这一轮」。记下选卡、点选或超时、第一次转向、使用的技能、是否失血和是否提前退出。
2. 第一轮结束后先问「你有没有改变走位？当时看到了什么？」和「哪一轮弹流有变化？你觉得是因为什么？」先记原话，再从录屏核对后排是否在发射前被击毁，以及实际出来几股弹。把观察和推测分开。
3. 问「你想现在重试吗？这一次打算试什么？」愿意就让他直接重开。第二轮单独记录。保留走中路、没认出差别和不想重试的记录。

本机模拟检验了机制和控制。新人是否会主动变线、认出弹流变化、愿意重试，需要手机试玩确认。
