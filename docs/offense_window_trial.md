# 45 秒进攻窗口试飞

从标题点「试飞任务 → 进攻窗口」，选贯穿弹芯或高爆弹头。选卡前可以勾选「旧版对照」。选卡后开始 45 秒计时。飞行中可点「重试」，桌面也可按 R，重试沿用所选版本。结果画面可重开或返回标题。这个入口只记录本次试飞的击杀和时间，普通进度和排行榜照原流程处理。

五组交战各占 540 个物理帧。每组左侧三机先纵向对齐，前两架在第一轮扇弹过后散开。右侧两机从不同位置入场后聚拢。每次齐射由还在场的后排各发三颗慢弹，射线留出中路。已经打出的弹继续飞行。下一组左队的轴线会移位。

## 第二版

首组的第一轮齐射从第 166 帧移到 188 帧，纵队随之多保持对齐 22 帧。第 244 帧的第二轮齐射和其余四组的发射时刻沿用旧版。两侧发射者从第 96 帧开始显示琥珀色蓄力弧，临发时弧线收紧并提亮。旧版首个蓄力弧出现在第 118 帧。

击毁正在蓄力的后排时，四段断弧在该机原位散开，200 毫秒内消失，同时播放用两段衰减音合成的 96 毫秒降音。断弧在命中和弹体下面。首轮已经发出后，击毁该机不会补播首轮中断。若它已开始为下一轮蓄力，则以那一轮为准。

### 两种画幅的模拟触摸对照

种子 1121，1280×720 和 1600×720。脚本从同一位置开始横移，按指定帧转为斜向上飞。延迟量相对第 100 帧的转向，横偏是目标横坐标相对左队轴线的画布单位。每个延迟取 −12、0、+12 三个目标。四种组合的飞机航迹和五架敌机的实际出生一致。每格为两种画幅共六个样本，统计左路三颗弹全部被截断且右路三颗照常发射的场次。

### 复跑与录制

```bash
python3 tests/run_first_card_probe.py /tmp/offense-window-v2 --offense-window-v2
python3 tests/run_first_card_probe.py /tmp/offense-window-v1 --offense-window

out=$(mktemp -d)
godot --path . --windowed --resolution 1280x720 --fixed-fps 60 --disable-vsync \
  --audio-driver Dummy --write-movie "$out/pierce.avi" --quit-after 400 \
  res://tests/offense_window_probe.tscn -- pierce rush --touch-flight --first-wave --delay=24 "--capture=$out"
```

另建目录把 `pierce` 换成 `power`，即可录同航线的正常发射。图形窗口可用 1600×720，探针末尾加 `--legacy` 可录旧版。第 126 帧查看发射者的蓄力提示，第 190 帧查看原位断弧或正常弹流。脚本固定输入并清除命中定格，实弹仍经由游戏物理碰撞。两版各 60 段首组记录在 `matrix.json`，含左右来源、弹数、后排击毁帧、机体失血和每次中断。新版另跑 8 局完整 45 秒。勾选旧版后的 60 条航迹、出生、击毁和弹流逐条对过基线 `5c40799`。

## 无提示真人盲玩

1. 从标题进试飞。多名新人时，由观察者交替安排旧版和新版先开始。只说「选一张你想试的卡，然后自由飞」。记录所选卡、是否主动换线、是否失血或提前退出。
2. 第一轮结束后先留几秒，记录玩家有没有自发按重试，再问「你刚才看到了什么？」「当时为什么换了路线？」原话与录屏核对分开记。核对后排的击毁时刻及实际出了几股弹。
3. 玩家愿意再玩就记录第二轮。保留走中路、没认出差别和没有重试的样本。

以上对照来自 Mac 的 Godot 实拍和模拟触摸。手机上的拇指容错、扬声器听感和首次游玩时能否读懂提示仍待验证。
