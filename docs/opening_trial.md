# 90 秒开场试飞

从标题选择「开场试飞 · 90 秒」。桌面按 R 重试，也可按 Esc 释放鼠标后点「重试」。手机点「重试」即可。重试从普通主炮和第 0 秒开始，返回标题可以再进 45 秒进攻窗口或普通单人。

## 三段战斗

| 时间 | 场上发生的事 |
| --- | --- |
| 0–20 秒 | 单架敌机先出现蓄力弧，临发时炮口露出三条短线。击毁正在蓄力的敌机，原位出现短断弧。漏掉时扇弹继续沿实际弹道飞行，旁边留出绕行空间。 |
| 20–55 秒 | 普通居中三选一提供贯穿、溅射和威力。试飞的排期等确认或原有十秒超时，飞机仍可移动和开火。随后同屏出现纵列、聚团与侧翼单体。左队前后隔开，右侧一架设为本场的 7 点生命目标。 |
| 55–90 秒 | 首组队形镜像并整体错位，第 3455 帧由生产入口生成一架裂隙猎手。中段护航弹流与入场重叠，截断那股弹可以从下方靠近精英继续输出。也可绕开、活到倒计时结束。收尾还有两次短侧翼齐射。 |

90 秒指战斗时钟，另计选卡用时。原型复用正式场景、自动主炮、敌机碰撞、精英和三选一。主炮在本局实际是 4 点，威力卡是 7 点，溅射为周围目标结算半伤。7 点生命只用于试飞侧翼。原型结束清理敌弹、触摸归属和草稿，结果只统计本次截断。

## 固定输入结果

种子 90220，两种视口为 1280×720 和 1600×720。基本教学从初始状态起步，普通主炮分别在第 215／229 帧击毁发射者，观察到一次断弧和零发敌弹。对照绕行时第 252 帧发出三颗实弹，玩家不接触弹体。两组都没有领取构筑。

第 1290 帧开始的首组构筑对照。每条航线使用相同的触摸指令和敌机出生。两种画幅的首轮弹数一致。

| 航线 | 匹配卡的实际结果 | 换卡后的代价 |
| --- | --- | --- |
| 纵列 | 贯穿的同一颗主炮弹第 1464 帧打中前机，第 1481 帧打掉后排，左路 0 发。 | 两张交换卡到第 1496 帧才击毁后排。第 1491 帧已发出三弹，继续贴线损失 1 点护盾。 |
| 聚团 | 溅射第 1472 帧直接击毁中间目标，同一发波及两架侧邻，中央 0 发。 | 交换卡清不了同一组聚团，第 1492 帧中央发出三弹。宽屏继续向上会损失 1 点护盾。 |
| 侧翼 | 威力第 1475 帧以一颗实弹击毁 7 点生命的目标，侧翼 0 发。 | 贯穿、溅射都要两次实弹接触。第 1483 帧已齐射三弹，继续贴线损失 1 点护盾。 |
| 绕行 | 在中央和侧翼的弹流之间穿行。 | 两种画幅三股都发出，绕行没有弹体接触或失血。 |

第 55 秒的护航聚团由溅射在第 3487 帧清掉发射者。继续向前后，在距离精英 300 个画布单位内记录到七次主炮命中，最近约 217 单位。威力同航线下，护航机在第 3502 帧发出三弹，第 3522／3523 帧有一颗碰到玩家。精英自己的弹幕仍需躲避。

两种画幅的完整绕行都到达第 5400 帧，护盾、机体及敌弹接触记录均为零。末段五股预告扇弹均正常发出，精英到时间结束时仍在场。窄屏第 1932 帧的聚团中有一架发射者在蓄力前被自动主炮碰巧击毁，整局为 16 股定时扇弹，宽屏为 17 股。两局都没有发生蓄力中断。

## 复跑

```bash
godot --headless --path . --editor --import
godot --path . res://scenes/opening_trial.tscn
python3 tests/run_opening_trial_probe.py /tmp/opening-90s
python3 tests/run_first_card_probe.py /tmp/opening-45-v1 --offense-window
python3 tests/run_first_card_probe.py /tmp/opening-45-v2 --offense-window-v2
bash tests/run_probe.sh 19491
```

复跑目录保存每段日志、出生、预告、实弹、直接与溅射接触、击毁及损失。两张卡有不同的击毁和受击结果，录像并排时按相同物理帧排列。录制脚本去掉了墙钟驱动的命中定格；摇杆、扣血、命中和发射用游戏路径。终段绕行脚本只读取屏内实弹来选转向，通过同一摇杆执行。

普通关卡的难度断言 14/14、波次断言 25/25。难度探针退出时有资源告警，原始基线 `767f4e2` 独立导出后三次均能复现，详细日志指向 `UpgradeDraft` 探针实例。

```bash
out=$(mktemp -d)
godot --path . --windowed --resolution 1600x720 --fixed-fps 60 --disable-vsync \
  --audio-driver Dummy --quit-after 1730 res://tests/opening_trial_probe.tscn \
  -- pierce column --first-build "--capture=$out"
ffmpeg -framerate 60 -start_number 1355 -i "$out/frame-%05d.jpg" -pix_fmt yuv420p "$out/column.mp4"
```

同一画幅另建目录换用 `power column` 可看左路开火。聚团用 `splash cluster` 和 `pierce cluster`，侧翼用 `power wing` 和 `splash wing`。首段用 `--intro`，从第 132 帧串图；精英段用 `--finale-clip`，从第 3430 帧串图并把 `--quit-after` 调到 3800。指定 `--press-finale` 走同一条贴近精英的路线。

## 无提示盲玩

1. 把原型交给第一次玩的人，只说「选你想用的卡，自由飞」。首段观察玩家是否注意发射者、主动改变航线，或从旁边绕开。
2. 记录选卡、第一条主动飞的路线、第一次截断或发射，以及碰到弹还是自己让开。结束后先等几秒，观察有无自发重试，再问「你看到哪股弹有变化？为什么？」
3. 玩家愿意才开第二局，问会试哪张卡或哪条路。记录看不懂、没截断、选择绕过和中途退出。观察过程与玩家原话分开。

现有记录来自 Mac 上的 Godot 实拍和模拟触摸。手机真机与真人理解、重玩动力仍待验证。
