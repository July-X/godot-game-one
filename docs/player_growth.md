# 普通局前期成长与触屏技能

普通单人和双人战斗在团队第四次击毁时校准两架飞机的主炮，基础速度从每秒 660 提至 900 逻辑像素。命中伤害、齐射弹数和出弹间隔由原有武器和卡牌计算。普通敌机同帧吃到多颗炮弹时只计一次击毁。第十击首卡推荐过载扳机，选中后基础开火间隔从 0.252 秒降到 0.216 秒。十秒超时由房主自动选推荐，手选仍按实际卡片确认。

闪避位于安全区右下方，触区为 108×108，激光和散射位于内上方，触区各 74×74。短画布等比收至约 80×80 和 55×55。手机用轮廓、图标明暗及就绪横线显示状态，只有激光和散射显示整数冷却。技能冷却仍为激光 10 秒、散射 15 秒、闪避 1.1 秒。左指保持走位时，另一指可以释放技能或选卡。

主炮校准和首卡推荐分别进入现有局内状态与选卡快照，协议为 10。房主在加入端普攻批次生成实弹前应用主炮速度。正常出弹、倒地、恢复、重试继续使用原有传输与局号。两个输出技能仅在确认后生成一轮弹体，拒绝的次数随本机状态回执，恢复只读当前冷却。裂隙与固定试飞使用各自原有成长规则，共用触屏控件。

## 复跑

在项目根目录运行，以下命令默认使用 `godot`。此轮记录使用 Godot 4.7.2。可用 `GODOT` 为外壳脚本和 Python 探针指定引擎绝对路径。

```sh
python3 tests/run_player_growth_probe.py /tmp/player-growth-ab
PROBE_KEEP_LOGS=1 bash tests/run_probe.sh 24861 draft-touch-wide-host
PROBE_KEEP_LOGS=1 bash tests/run_probe.sh 24862 draft-touch-wide-client
godot --headless --path . res://tests/draft_touch_probe.tscn -- solo 0 compact
godot --headless --path . res://tests/draft_touch_probe.tscn -- solo 0 keys
PROBE_KEEP_LOGS=1 bash tests/run_probe.sh 24863
PROBE_KEEP_LOGS=1 bash tests/run_probe.sh 24913 draft
PROBE_KEEP_LOGS=1 bash tests/run_probe.sh 24925 resume-guest "$(mktemp -d)"
PROBE_KEEP_LOGS=1 bash tests/run_probe.sh 24926 rescue
python3 tests/run_first_card_probe.py /tmp/player-growth-first-card
python3 tests/run_dual_intercept_probe.py /tmp/player-growth-dual --case center --case both --case downed --case mismatch
```

图形对照从标题进入普通单人，给桌面窗口注入移动端控件与非对称安全区，分别保存技能就绪和三项技能已施放的画面。将此轮的 `player_growth_probe.gd` 和同名场景复制到单独解包的基线项目，即可用相同命令拍基线。

```sh
godot --path . --windowed --resolution 1600x720 res://tests/player_growth_probe.tscn -- solo capture /tmp/player-growth-wide wide
godot --path . --windowed --resolution 960x720 res://tests/player_growth_probe.tscn -- solo capture /tmp/player-growth-tablet tablet
```

基线单人第三架击毁时团队计数已到 4，第四架时为 5。修正后首卡和后续门槛等待独立击毁，首领入场时间会变化。单人 A 在第 3285 帧入场、第 3686 帧首次伤及本体，B 为第 5196、5764 帧。双人 A 为第 3267、3493 帧，B 为第 5086、5341 帧。前两阵的弹量是固定航线样本里的同时在场数量，受命中时间和敌人是否有机会出弹影响。
