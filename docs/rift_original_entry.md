# 原版裂隙航道双人开局

Godot 4.7.2，基线 `aaf69ade804e386862c94e28f80dff0d20d6dd42`。从标题打开多人大厅，以默认的原版裂隙规则开局。探针通过本机地址建立真实双进程 ENet 会话，脚本注入鼠标位移，主炮按游戏原有规则发射。由房主确认加入者同一稳定槽位的实际位置与非表现弹。

## 基线与门槛

本机基线 12 局均在一秒内收到首弹与位移，其中第 12 局未达续射门槛。以最早战斗场景就绪为零点，该局加入端在 254 毫秒实际移动、255 毫秒发送首批。首批和第二批发送计数／限流值为 21／0 和 6／4，房主未进入对应的接收点。第三批计数 1、限流值 4，房主在 674 毫秒收到并同毫秒生成实弹。房主首次应用移动在 475 毫秒。后续只观察到一批，且在首弹后 1334 毫秒才到。

ENet 在发送队列处理不可靠包时，用计数和限流值决定是否丢弃。收到低延迟确认时，回升步长决定下个限流值提高多少。[Godot 4.7.2 自带的 ENet 发送队列](https://github.com/godotengine/godot/blob/4.7.2-stable/thirdparty/enet/protocol.c#L1383-L1412) · [ENet 回升规则](https://github.com/godotengine/godot/blob/4.7.2-stable/thirdparty/enet/peer.c#L55-L83)

以同一引擎、同机、同探针交替跑基线和候选。验收按两端较早战斗场景就绪起一秒内确认同槽位位移与首颗权威实弹，之后 1300 毫秒内再收到两批不同的权威弹。按批次对齐发送、房主接收及生成，检查重复、错槽，并保留每局双端日志。

## 改动范围

原版裂隙加入端复用普通局已有的临时 ENet 回升步长。保留原采样周期、回退步长、输入与弹体的传输方式和协议 9。确认入局后 1500 毫秒恢复原配置，超时、断线等待和离场沿用现有清理路径。原版航道的首波排期保持原样。

## 同机交替对照

12 对样本交替先跑基线或候选，同一对使用相同房主画幅。两组各 12 局通过。基线最慢确认 433 毫秒，候选最慢 425 毫秒。候选第 5 局首批同样在计数 21／限流值 0 时丢弃，发第二批时已回升到 32，房主在 424 毫秒收到，后续两批在首颗实弹后 266、532 毫秒到达。候选 11 局从第一批收到实弹，其余 1 局从第二批收到。本机复现了限流丢发及续射长尾，历史云端超过一秒的首发长尾在本机未重现。

## 复跑命令

从仓库根目录运行。`GODOT` 指向 4.7.2，可省略环境变量并使用 `PATH` 中的同版本引擎。基线副本仅替换探针，生产代码来自原提交。

```bash
export GODOT=godot
baseline=$(mktemp -d)
git archive aaf69ade804e386862c94e28f80dff0d20d6dd42 | tar -x -C "$baseline"
cp tests/lobby_start_probe.gd tests/run_lobby_entry_probe.py "$baseline/tests/"
"$GODOT" --headless --path "$baseline" --editor --import
"$GODOT" --headless --path . --editor --import
python3 tests/run_lobby_entry_probe.py /tmp/rift-base --rift-only 12 --baseline-project "$baseline" --start-port 21630
python3 tests/run_lobby_entry_probe.py /tmp/rift-life --rift-only 0 --rift-lifecycle --start-port 21720
python3 tests/run_lobby_entry_probe.py /tmp/rift-regression --normal-runs 4 --remix-runs 4 --normal-recovery --start-port 21700
python3 tests/run_dual_intercept_probe.py /tmp/rift-dual-regression
bash tests/run_probe.sh 21740
bash tests/run_probe.sh 21741 wide-host
bash tests/run_probe.sh 21742 wide-client
bash tests/run_probe.sh 21743 rift-wide-host
bash tests/run_probe.sh 21744 rift-wide-client
bash tests/run_probe.sh 21745 rift-duo-host
bash tests/run_probe.sh 21746 rift-duo-client
```
